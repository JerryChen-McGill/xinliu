# 产品功能说明：心流 FLOW LAB

## 1. 产品目标

帮助没有心理学背景的读者在约 5 分钟内理解心流的基本概念，并能继续查看理论论证、研究局限和原始资源，或立即设计一次专注练习。首页以巨大 FLOW 字形、深色背景、荧光绿交互地图建立辨识度；研究区用浅紫作视觉区分，阅读区用明亮底色收束。

## 2. 用户路径与信息架构

| 深度 | 路径 | 用户获得什么 |
| --- | --- | --- |
| 浅尝 | 首页地图 → 三张观点卡 | 理解投入、挑战与能力、目标与反馈 |
| 深入 | 展开论证 → 研究区 → 阅读资源 | 区分原著观点、相关证据、因果限制与测量问题 |
| 实操 | 选择场景 → 目标与反馈 → 计时 → 复盘 | 一次有边界、可观察的尝试 |

单页锚点导航：`#home`、`#theory`、`#evidence`、`#practice`、`#resources`。资源有独立 `#source-*` 锚点；即使先筛选，正文来源链接也会恢复全部资源并定位目标。

## 3. 功能规格

### 3.1 交互心流地图

- 挑战、能力均为 1–10 滑块；实时更新坐标、区域文字与建议。
- 教学规则：两者都 ≤4 为低投入；挑战高于能力 ≥2 为偏焦虑；能力高于挑战 ≥2 为偏无聊；差距小于 2 且均 ≥6 为接近心流；其余为逐渐投入。
- 这些数字是界面演示阈值，不是研究推出的分界值。图中带状区域也是示意，不代表诊断概率。
- 滑块支持键盘，结果通过状态区域更新；默认 7/7。

### 3.2 分层导读

- 三张卡片默认简洁，可展开观点、论证、例子和来源。
- 阅读路线按原著章节推荐；说明心流与专注、放松的差别。
- 原著并未被逐章完整转写；不提供侵权全文或冒充特定译本。

### 3.3 研究与理解检查

- 三条证据：挑战—能力元分析、表现关系元分析、研究范围综述。
- 每条同时呈现结论与适用边界，不宣传保证高效或固定心流触发公式。
- 一个概念判断题：选择后即时解释，不生成能力评分。

### 3.4 专注实验

- 五个场景；四组可编辑预设，自定义为空白。
- 目标和反馈必填且不接受纯空白，长度各 ≤180 字符。
- 10/25/45 分钟，25 分钟默认；明确说明这不是科学阈值。
- 准备事项需主动确认。开始后锁定任务，防止计时与计划不一致。
- 暂停/继续、提前结束、自然倒计时结束，均有明确状态。
- 暂停时间不计入实操时长；返回后台页面会根据截止时间校正显示。
- 结束后选择体验并写下一次调整（≤500 字符）；保存后可再次练习。
- 刷新/关闭可能丢失未保存练习，因此在练习或待复盘时使用浏览器离开提醒。

### 3.5 记录

- 当前浏览器保存最多 100 条，显示最近 5 条；导出包含全部记录的 JSON。
- 保存日期为 ISO 时间，展示按浏览器本地时区格式化。
- 包含任务、反馈、计划时长、实际秒数、自然完成标志、体验和笔记。
- 对用户输入只写入 `textContent`，不解释为 HTML。
- 存储不可用或数据格式异常时给出可理解提示，仍可练习并导出。
- 清空有确认；无云端备份、账号、分析埋点或跨设备同步。

### 3.6 阅读资源

- 六条来源，支持全部/入门/研究筛选。
- 包含原著馆藏、理论章节、两项元分析、范围综述、作者演讲。
- 标注作者、年份、类型、摘要用途与访问门槛；外部链接新窗口打开并设置 `noopener noreferrer`。

## 4. 实现与交付

原生 HTML/CSS/JavaScript，零运行依赖。`node server.mjs` 提供本地预览。GitHub Actions 检查通过后上传四个公开文件并发布 Pages；首次启用 Pages 可能需要管理员选择 Actions 来源。

## 5. 验证范围

自动检查：语法、唯一元素 ID、静态资源完整、核心锚点、本地 HTTP 服务与非公开文件不可访问。

浏览器验收：地图键盘调整、概念问答、准备/开始、暂停、提前结束、复盘保存、刷新持久化、资源筛选和来源跳转；桌面与窄屏的首页及主要内容布局。自然计时完成分支使用隔离测试时钟验证。

已知边界：没有对所有浏览器组合进行测试；字体加载依赖外部网络；关闭页面后计时不继续恢复；不能在页面关闭时通知；设备系统时间跳变可能影响计时。没有声称达到完整 WCAG 认证。

## 6. 后续维护

新增研究时更新 `app.js`、对应正文与 `SOURCES.md`，记录核对日期、获取范围和局限。不要把单项研究结果升格为普遍因果结论。修改交互后重新执行检查并实际走完一次练习流程。
